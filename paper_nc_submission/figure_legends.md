# Figure Legends

**Fig. 1 | SCRS as a temporal-hypergraph system architecture.** Temporal interaction is represented as a layered hypergraph stack with an integrated exposure signal, and SCRS is represented as a matrix role filter that masks defective channels while transmitting cooperative role models into the candidate pool. The signal-flow track links group payoff, context sampling, role screening and Fermi adoption, with feedback from strategy updating to subsequent temporal states. Source data are provided as Source Data files.

**Fig. 2 | Main performance and initial-condition boundary.** Panels a-d show point-line summaries of SCRS tail cooperation and the strongest competing control across the four empirical temporal hypergraphs; panel e shows the empirical \(r\times\rho_0\) phase surface with cooperation iso-contours; panel f shows paired gaps against principal controls. The near-zero score-shuffled gap marks the boundary of claims about fine edge-score ordering. Source data are provided as Source Data files.

**Fig. 3 | Mechanism decomposition identifies cooperative role screening.** Violin distributions with jittered cell-level observations, paired loss gaps and a data-derived evidence profile show that role-screen-disrupted controls lose most of the SCRS advantage, whereas score-shuffled and random eligible-cooperator controls remain near SCRS. Source data are provided as Source Data files.

**Fig. 4 | Null-model preservation, mutation boundary and synthetic stress tests.** Null-model schematics, gap-change heatmaps and SCRS-level heatmaps show that temporal and topological perturbations preserve the SCRS advantage; the mutation phase diagram and synthetic topology-size heatmaps identify boundary and stress regimes. Source data are provided as Source Data files.

**Fig. 5 | External extrapolation and implementation sensitivity.** External dumbbell plots, paired-gap summaries and retained-event heterogeneity show that external empirical datasets preserve positive SCRS gaps, while payoff/update and mutation-noise panels identify per-capita payoff and high mutation as boundary regimes rather than reversals. Source data are provided as Source Data files.

**Supplementary Figs. S20-S27 | Complete formal experiment source views.** Each formal experiment group has complete supplementary source, case, cell, pairwise, paired-gap, mechanism or QA tables, as available. These files preserve the S20-S27 evidence behind the main figures and should be used for detailed cell/source/case panels in the supplement.

**Supplementary Fig. S28 | Hypergraph construction sensitivity.** Construction-slice heatmaps and paired-gap summaries show that SCRS remains above Wang imitation, CSGC and strategy-shuffled SCRS across edge size, edge count, temporal-block duration and construction-mode variants, while score-shuffled SCRS remains the claim boundary. Source data are provided as Source Data files.

**Supplementary Fig. S29 | Clean mechanism-context controls.** Clean controls show that SCRS is far above role-disrupted strategy shuffling but is close to generic local cooperator-search rules, narrowing the claim to local cooperative role screening under temporal-hypergraph exposure. Source data are provided as Source Data files.

**Supplementary Fig. S30 | Structure-stratified moderator audit.** Temporal memory and within-block hyperedge overlap increase the paired SCRS gap against strategy-shuffled SCRS, whereas score-shuffled gaps remain near zero across strata. Source data are provided as Source Data files.
